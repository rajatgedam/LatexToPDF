## How to continue safely
- Test first. Backend gate: `npm run coverage` (>= 80% lines on `src/`). Web gate: `npm --prefix web run coverage`.
- Any new LaTeX capability goes through `src/validate.mjs` rules plus a test in `test/unit/validate.test.mjs`; read `SECURITY_RULES.md` first.
- After each milestone: append to `PROGRESS.md`, update `ARCHITECTURE.md` if behavior changed, create a new `HANDOFF_<date>.md` for a new session (keep old ones), commit, push.

## Gotchas
- Do not use `brew install tectonic` (see PROGRESS.md).
- Repo root is `RGit/LatexToPDF` (its own git repo, parent folder is not a repo).
- Integration tests need internet on the first run (Tectonic downloads packages); afterwards they use `vendor/tectonic-cache`.
- Node test runner runs test files in parallel; keep temp dirs private per test file.
