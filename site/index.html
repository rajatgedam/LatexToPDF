ToolMaster, all local

A menu of small, free tools that run on your machine: convert LaTeX to PDF or Word today, more tomorrow. No accounts, no uploads.

Download View on GitHub

Tools

LaTeX to PDF

Typeset LaTeX (or plain text) into a print-ready PDF with live preview. Great for resumes.

Engine: Tectonic (MIT)

LaTeX to DOCX

Turn LaTeX into an editable Word document: headings, lists, tables, links and math carry over.

Engine: Pandoc (GPL-2.0+, separate program)

PDF Pages

Pick, reorder, reverse, repeat, delete or rotate pages. Splitting a PDF is just extracting a range.

Built in, runs in a sandboxed worker

Doc to Markdown

Read PDF, Word, PowerPoint, Excel, EPUB, HTML and CSV files as clean Markdown, made for AI to read.

Pandoc and pdf.js, no cloud

Your tool next

Each tool is a small self-contained module. Add a folder, it appears in the menu, the CLI and the API.

Take only what you need

Download and double-click

One zip per OS (macOS Apple Silicon and Intel, Linux x64 and arm64, Windows x64), as all or any single tool. Everything is about 79 MB; one engine-free tool is under 1 MB as a -lite download if you have Node. No installs otherwise.

Verify with SHA256SUMS.txt. Builds are unsigned, so macOS and Windows may warn on first run.

Docker (any OS)

docker run --rm -p 127.0.0.1:5757:5757 \
  ghcr.io/rajatgedam/toolmaster

Also one image per tool, for example toolmaster-pdf-pages. Runs as non-root.

For AI agents and scripts

toolmaster doc-to-markdown -i report.pdf -o -
toolmaster mcp   # every tool over MCP

One JSON result, stable exit codes, an MCP server, a Node API and an HTTP API. Agents call a tool instead of writing a script.

Why there is no "convert online" button here

GitHub Pages can only host static files, and running other people's documents on a public server is a real security risk (LaTeX can read files and run programs unless it is locked down). It would also mean your resume travels to someone else's computer. So the tools run locally, where your files stay yours. This page is just the front door.

Security in one paragraph

Loopback-only server, Host and Origin checks, strict CSP, rate limits and size caps. Every engine and every PDF parser runs in a separate process with an isolated temp folder, a timeout, a memory limit, a scrubbed environment and, on macOS, an OS sandbox that blocks your home folder and the network; LaTeX is policy-scanned and Pandoc runs with its own sandbox. Engine downloads are pinned by SHA-256, the core has no runtime npm dependencies, and release files carry build provenance attestations.
